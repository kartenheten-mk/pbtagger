# Applikationens delar

Den här delen beskriver gränssnittets huvudytor och vad de ansvarar för.

![Editorläge med dokument, sidopanel och kartpanel](../assets/screenshots/editor-oversikt.png)

*Editorläget samlar dokumentvy, sidopanel, kartpanel och toppbar.*

## Huvudytor

| Del | Ansvar |
| --- | --- |
| Startvy | Skapa, importera, öppna och ta bort projekt. |
| Toppbar | Projektstatus, taggantal, synlighet, ångra/gör om, validering och dataåtgärder. |
| Dokumentvy | Renderar DOCX-innehåll, hanterar markeringar och visar taggar. |
| Sidopanel | Tilldelar taggar och visar befintliga taggar. |
| Kartpanel | Visar geometrier, filter och länkningsläge. |
| Datameny | Samlar import, export inklusive tagg-JSON, config och Planbeskrivning-inställningar. |
